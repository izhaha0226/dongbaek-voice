# 동백

맥미니 음성 비서. 입력 경로 3개(상시대기 / 푸시투토크 / 아이폰 텍스트)가
같은 Claude 세션과 같은 안전 게이트를 공유한다.

---

## 돌아와서 할 일 (순서대로)

### 1. Claude 인증 — 필수

```bash
claude
```

대화창이 열리면 로그인하고 `/exit`. 이게 안 되면 데몬이 안 뜬다.
확인:

```bash
~/dongbaek/.venv/bin/python ~/dongbaek/dongbaek.py --check
```

### 2. 마이크 없이 먼저 돌려보기

```bash
~/dongbaek/run.sh
```

마이크가 없으면 제어 서버만 뜬다. 이 상태로 아이폰 텍스트 직송은 동작한다.

### 3. 마이크가 도착하면 (Anker PowerConf A3301)

**USB-C 케이블로** 맥미니 전면에 꽂는다. 블루투스로 붙이면 배터리·HFP 음질 문제가
그대로 오므로, 상시 대기용으로는 반드시 유선으로 쓸 것.

> 📌 **시스템 설정 → 사운드 에서 입력과 출력을 둘 다 PowerConf 로 맞출 것.**
> AEC(에코 제거)는 "지금 내 스피커로 나가는 소리"를 기준 신호로 삼아 마이크에서
> 빼는 방식이라, 출력이 다른 기기면 뺄 대상을 몰라 동작하지 않는다.
> 둘을 맞춰야 동백 말을 중간에 끊을 수 있다.

그다음:

```bash
~/dongbaek/.venv/bin/python ~/dongbaek/dongbaek.py --devices   # 잡히는지 확인
~/dongbaek/.venv/bin/python ~/dongbaek/dongbaek.py --listen    # 받아쓰기만 테스트
~/dongbaek/run.sh                                            # 본 실행
```

> ⚠️ **처음에는 반드시 터미널에서 실행할 것.** macOS 마이크 권한 창이 떠야 한다.
> launchd 로 먼저 띄우면 권한 창이 안 뜨고 무음만 녹음된다.

권한을 허용한 뒤 상시 실행으로 넘기려면:

```bash
cp ~/dongbaek/com.dongbaek.dongbaek.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.dongbaek.dongbaek.plist
```

## 명령어

| 명령 | 하는 일 |
|---|---|
| `run.sh` | 데몬 실행 |
| `dongbaek.py --check` | Claude 연결 확인 |
| `dongbaek.py --devices` | 입력 장치 목록 |
| `dongbaek.py --listen` | 받아쓰기만 (Claude 미호출, 0 토큰) |
| `dongbaek.py --text "명령"` | 마이크 없이 명령 경로 테스트 |
| `dongbaek.py --log` | **동백이 한 일 보기** (들은 말·답변·비용·차단 이력) |
| `dongbaek.py --reset` | 세션 초기화 (컨텍스트가 비대해졌을 때) |
| `dongbaek.py --enroll [이름]` | **목소리 등록** (기본 이름: 사장님, 같은 이름은 지문 누적) |
| `dongbaek.py --voices` | 등록된 목소리 목록 |
| `dongbaek.py --forget 이름` | 등록된 목소리 삭제 |
| `python test_router.py` | 호출어·위험 게이트·라우팅 |
| `python test_control.py` | 제어 서버 보안 (HTTP 우회 차단) |
| `python test_tts.py` | 음성 합성 파이프라이닝 |
| `python test_korean_time.py` | 한국어 날짜·시각 파서 |
| `python test_local.py` | **로컬 처리가 안전 게이트를 우회하지 않는지** |

## 제어 API

토큰은 `state/token.txt` (최초 실행 시 자동 생성).

```bash
TOKEN=$(cat ~/dongbaek/state/token.txt)

curl "http://127.0.0.1:8765/status?token=$TOKEN"
curl "http://127.0.0.1:8765/ptt?token=$TOKEN"          # 푸시투토크 8초 개방
curl -X POST "http://127.0.0.1:8765/command?token=$TOKEN" \
     -H 'Content-Type: application/json' \
     -d '{"text":"오늘 일정 알려줘"}'
```

위험 명령은 `409` 와 함께 보류된다. 통과시키려면:

```bash
curl -X POST "http://127.0.0.1:8765/command?token=$TOKEN" \
     -H 'Content-Type: application/json' \
     -d '{"text":"프로덕션 배포해","confirm":"진행"}'
```

### 아이폰 연동

`config.py` 의 `CONTROL_HOST` 를 `"0.0.0.0"` 으로 변경 (맥 LAN IP: `192.168.194.18`).

아이폰 단축어: `텍스트 받아쓰기` → `URL 콘텐츠 가져오기`(POST, 헤더 `X-Dongbaek-Token`,
본문 `{"text": 받아쓴텍스트}`) → `말하기`.

> ⚠️ `0.0.0.0` 은 같은 와이파이의 누구나 접근 가능하다는 뜻이다. 토큰이 유일한 방어선이다.
> 공용 와이파이에서는 켜지 말고, 외부에서 쓸 거면 포트 개방 대신 Tailscale 을 쓸 것.

## 대화 방식 — 말이 다 끝난 뒤에 답한다

사람과 사람처럼 주고받는 걸 목표로 한다.

```
나:   동백아, 광고플랫폼에 들어가면…  (2초 쉼)  거기 용탐 밸리라고 있잖아…
      (2초 쉼)  우리 광고주 중에 그 데이터를 확인해줘
동백: (세 조각을 한 덩어리로 받아 한 번만 답한다)

동백: (답하는 중) 데이터는…
나:   아, 그리고 지난달 것도 같이
동백: (즉시 입을 다물고, 앞 질문과 합쳐 통째로 다시 답한다)
```

**끝까지 듣는다.** 침묵 1.4초를 무조건 '명령 끝' 으로 보면 생각하느라 쉬는
사이에 잘린다. 잘린 반쪽을 명령으로 받아 답하기 시작하니 사장님 입장에선
끼어드는 것이다. 실측으로 최근 음성 명령 60건 중 **10건이 문장이 끊긴 채**
실행됐다 (`'일단 그 부분보다도'`, `'그래서 어떻게 하겠다고.'`).

그래서 한 발화가 끝나도 곧바로 처리하지 않고 잠깐 더 듣는다.
말이 중간에 끊긴 것처럼 보이면 더 오래 기다린다:

| 마지막 말 | 판정 | 기다리는 시간 |
|---|---|---|
| `…들어가면`, `…그리고`, `…미팅은` | 아직 안 끝남 | 3.0초 |
| `…알려줘`, `…몇 시야`, `…하겠다고` | 끝난 말 | 1.2초 |

연결어미(`~면`, `~하고`, `~는데`)나 조사로 끝나면 뒤에 할 말이 남아 있다는
뜻이다. 다만 `~다고`·`~라고` 는 인용형 **종결**이라 끝난 말로 본다.

**보태면 합쳐서 다시 답한다.** 동백이 답하는 도중에 말을 보태시면 입을 다물고,
앞에서 하신 말과 합쳐 통째로 다시 묻는다. 반쪽만 듣고 만들던 답은 버린다 —
어차피 쓸모가 없다. 진행 중인 호출을 중간에 죽이긴 어려우니 '세대' 를 매겨
지난 세대의 답은 말하지 않는다.

## 끼어들지 않기 — "이 말, 나한테 한 건가"

화자 인증은 **누가** 말했는지만 안다. TV 앞에서 가족과 나누는 말도 사장님
목소리다. 그래서 답하기 전에 한 번 더 묻는다 — `router.is_for_me()`.

| 들린 말 | 판단 |
|---|---|
| "너 뭐하냐?" · "지금 몇 시니?" | 받는다 (2인칭·짧은 물음) |
| "내일 3시 치과 등록해줘" | 받는다 (시키는 말) |
| "형님 그러시더라고" · "그거 어딨어" | 물러난다 (타인 호칭·전언) |
| 120자 넘는데 지시로 끝나지 않는 말 | 물러난다 (받아쓰기다) |
| "생활 온도를 25도로 설정합니다" | 물러난다 (가전 안내) |

⚠ **세게 조이면 안 된다.** 실기록 425건에서 답한 것의 91%가 호출어 없이
들어왔고 그 대부분이 정당했다 — 대화창 안에서 이어 말하는 게 정상이기
때문이다. 그래서 기본은 '받는다' 이고, 남에게 한 말이라는 표시가 보일 때만
물러난다.

실데이터 채점판이 있다. 문턱을 만질 때마다 두 숫자를 같이 본다:

```bash
~/dongbaek/.venv/bin/python tools/eval_intrusion.py        # 채점
~/dongbaek/.venv/bin/python tools/eval_intrusion.py --list # 정답표
```

정답표는 규칙이 아니라 **행동 증거**로 만든다 — 사장님이 직후에 물리신 것
("안 불렀어", "그만"), 동백이 제 답에서 헤맨 것, 300자 넘게 이어 붙은
받아쓰기. 자기가 만든 규칙으로 정답을 매기면 시험이 제 얼굴을 비추는 거울이
된다.

## 새 메일 알림

새 메일이 오면 먼저 알린다 (5분 주기, 소리 + 텔레그램).

| 말씀 | 결과 |
|---|---|
| "메일 오면 알려줘" | 사람이 보낸 것만 (기본) |
| "강남 00건설에서 메일 오면 알려줘" | 그 발신인을 적어 두고 기다린다 |
| "메일 알림 전부로 해줘" | 서비스 알림까지 |
| "메일 알림 꺼" | 끔 (기다림 목록도 비운다) |

⚠ 기본을 '전부' 로 열지 않는다. 하루 40통을 다 읽으면 알림이 아니라 소음이다.
`mail_local.notice_service()` 가 서비스·자동 발신을 가려내므로 그 판단을 쓴다.
VIP(`config.MAIL_NUDGE_VIP`)와 기다리는 발신인은 방식과 무관하게 알린다.

## 통화·회의 정리 — 일정은 여쭙고 넣는다

통화가 끝나면(`"전화 끝났어"` 또는 30초 침묵) 오간 말을 정리해 옵시디언에
남긴다. 회의록·GPT 모드는 각각 다른 틀을 쓴다.

정리본에 **때가 분명한 일정**이 있으면 뽑아서 여쭌다:

> "일정 후보가 있어요. 8월 17일 오후 세시 세종 축산환경관리원 미팅,
> 외 1건. 등록할까요?"

"응" 하시면 그때 넣는다. 30분이 지나면 후보는 스스로 사라진다.

⚠ 바로 넣지 않는 이유 — 통화 받아쓰기는 메일보다 험하다. 같은 노트 안에서
이름이 '충무화(?)' 처럼 흔들린다. 그대로 넣으면 2026-08-15 에 지운 쓰레기
일정 56건이 되풀이된다.

## 화자 인증 — 등록된 목소리만 명령이 된다

TV·유튜브·방송 음악·옆 사람이 "동백아 …" 해도 실행되지 않는다.
발화를 ECAPA 임베딩으로 바꿔 등록된 지문과 코사인 유사도를 잰다. 전부 로컬, 0 토큰.

**등록은 말로 한다.** 마이크를 쥐고 있는 건 데몬이라, 터미널에서 따로 띄우면
같은 장치를 두고 다투고 사장님이 터미널 앞에 앉아 있어야 한다.

```
나:   동백아, 목소리 등록해줘 이름은 김철수
동백: 김철수 목소리를 등록하겠습니다. 5문장을 따라 말씀해 주세요.
      1번. 동백아 오늘 일정 알려줘
나:   (따라 읽는다)   … 5문장
동백: 확인하겠습니다. 아무 말이나 한 문장 해주세요.
동백: 김철수 목소리를 등록했고 확인도 됐습니다. 유사도는 0.62입니다.
```

이름을 빼고 "목소리 등록해줘" 라고만 해도 된다 — 동백이 이름을 되묻는다.
같은 이름으로 다시 등록하면 지문이 **누적**된다.

> 🔒 **등록도 화자 인증을 거친다.** 이미 등록된 사람만 새 목소리를 추가할 수
> 있다. 등록은 명령 권한을 나눠주는 일이라 아무나 하면 안 된다.
> (아무도 등록돼 있지 않은 처음에는 열려 있어 첫 등록이 가능하다)

데몬이 안 떠 있을 때는 터미널로도 된다:

```bash
~/dongbaek/.venv/bin/python ~/dongbaek/dongbaek.py --enroll 김철수
```

- **등록된 지문이 하나도 없으면 열려 있다** (설치 직후에도 동작해야 하므로).
  `--enroll` 하는 순간부터 잠긴다.
- 같은 이름으로 다시 등록하면 지문이 **누적**된다. 마이크 거리·컨디션이
  바뀌어 자꾸 차단되면 그 상태로 몇 문장 더 등록하면 된다.
- 미등록 목소리는 **조용히 무시**한다 (로그·`--log` 에는 남는다).
  승인 대기 중에는 미등록 응답을 5회까지 무시하고 그 뒤 취소한다 —
  방송에서 나온 "진행" 이 위험 명령을 통과시키지 못하게.
- 문턱은 `config.VOICE_VERIFY_THRESHOLD` (기본 0.30). 등록 마지막에
  본인 목소리 실측 점수를 보여주니 그걸 보고 조정한다.
- **등록 지문은 영구 보관한다** (지시 2026-08-16). 상한이 없고, 지우는 길은
  `--forget` 하나뿐이라 잘못 들은 음성으로는 사라지지 않는다. 그리고
  `state/voiceprints-enrolled/` 에 따로 뜬다 — `state/` 는 gitignore 라
  버전 관리 밖이고, 2026-08-13 에 같은 자리의 DB 가 자가개선 롤백의
  `git clean` 에 쓸려간 전례가 있다. DB 는 다시 쌓이지만 목소리는 사람이
  다시 등록해야 한다.
- **학습 지문(`#적응`)은 다르다.** 통과 점수가 0.60 을 넘을 때만 배우고,
  넘치면 **오래된 것이 아니라 가장 겹치는 것**을 버린다. 지문의 값어치는
  개수가 아니라 조건의 다양성이기 때문이다 — 판정이 최대값을 쓰므로 서로
  닮은 열 개보다 다른 조건 열 개가 낫다.

  > 2026-08-16 실측: 학습 대상이 하루 67건인데 상한이 10개라 최근 3.5시간치만
  > 남았다. 아침·먼 거리·감기 목소리가 그날 오후 잡담에 밀려 사라지고, 그러면
  > 같은 조건에서 매번 다시 거절당한다(문턱 근처 거절 39→85건). 상한을 40으로
  > 올리고 버리는 기준을 바꿨다.
- 텔레그램·아이폰 경로는 화자 인증 대상이 아니다 — 거긴 chat_id 와 토큰이 방어선.

## 권한 3단 — 경계는 단어가 아니라 도구다

whisper 오인식('배포'→'배표')은 단어 게이트를 뚫을 수 있다. 그래서 최종
경계는 Claude 에 주는 **도구**로 긋는다. 되돌릴 수 없는 일은 거의 전부 셸이
필요하다 — 배포·푸시·DB·광고 집행 전부. 코드 수정은 Write/Edit 만 있으면 된다.

| 등급 | 도구 | 모델 | 언제 |
|---|---|---|---|
| 조회 | **셸 없음** (읽기·쓰기·웹) | **소넷 5** | 평상시 대화·조회 — 실사용의 61% |
| **개발** | 전부 (셸 포함) | **오퍼스 5** | 코드 작업 — 음성 승인 없이 |
| 전권 | 전부 | **오퍼스 5** | 명시적 위험을 음성 승인으로 통과했을 때 |

> 🔒 **조회 등급에 셸이 없는 것이 지금 유일하게 남은 '도구로 그은 경계'다.**
> 되돌릴 수 없는 일(배포·푸시·DB·광고 집행)은 거의 전부 셸을 거친다.
> 실사용의 61%가 조회 등급이라 사고가 날 수 있는 표면이 그만큼 줄어든다.
> 오인식으로 '배포'가 음성 게이트를 빠져나가도 조회 등급이면 실행 자체가 안 된다.
> 실측: 조회 등급에 `date` 실행을 시키면 "셸 없이는 불가능합니다",
> 개발 등급에서는 실제로 실행된다.
> 파일 수정(Write·Edit)은 모든 등급에 남겨두었다 — 사장님 지시.

도구·권한·모델은 전부 `config.TOOL_POLICY` 한 표에서 온다. `bridge.ask` 는
그 표만 읽으므로, 정책을 바꾸려면 표만 고치면 된다.

> ⚠️ **지금은 도구 제한이 열려 있다** (사장님 지시). 원래는 경계를 '도구' 로
> 그었다 — 되돌릴 수 없는 일은 거의 전부 셸이 필요하므로, 개발 등급에서
> `Bash` 를 빼두면 whisper 가 '배포'를 '배표'로 적어 음성 게이트를 빗나가도
> 배포 자체가 불가능했다. **그 두 번째 방어선이 지금은 없다.**
> 되돌릴 수 없는 작업을 막는 건 `DANGER_PATTERNS` 음성 게이트 하나뿐이고,
> 그 게이트는 받아쓰기 정확도에 의존한다.
> 다시 좁히려면 `TOOL_POLICY["dev"]["disallowed"]` 에 `"Bash"` 를 넣으면 된다.

> 📌 **`--disallowed-tools` 에서 뺀 것과 '승인된 것' 은 다르다.**
> 목록에서 빼도 편집·셸은 여전히 승인을 요구하는데, `--print` 헤드리스에는
> **승인창이 없어** 그대로 거부된다. 사장님 눈에는 "고쳐달랬는데 아무 일도
> 안 일어남" 으로만 보인다. 그래서 `permission_mode` 를 반드시 함께 준다.
>
> 같은 이유로 **`CLAUDE.md` 의 '권한' 절도 함께 봐야 한다.** 예전엔 거기에
> "그 도구가 필요하면 실행하지 말고 음성 확인이 필요하다고 답해라" 가 적혀
> 있어서, 권한을 열어줘도 Claude 가 스스로 거부했다. 권한은 두 군데(CLI 인자와
> CLAUDE.md)에서 동시에 열려야 한다. `test_dev_mode.py [8]` 이 회귀로 고정한다.

**개발 모드 (`config.DEV_MODE = True`)**: "주석 달아줘" 마다 "진행할까요?" 를
거치면 음성 개발이 불가능하다. 그래서 코드 작업은 승인 대신 **사후 방어**로
간다 — 실행 전에 스냅샷을 강제로 남기고, "**되돌려**" 한마디로 복구한다.
게이트를 오인식으로 빠져나가도 개발 등급엔 셸이 없어 배포는 물리적으로 불가능하다.

## 안전 게이트 (음성 재확인)

명시적 위험(`config.DANGER_PATTERNS`)에 걸리면 실행 전에 되묻는다.

- **음성 경로**: "…. 진행할까요?" → 15초 대기 (동백이 말하는 동안은 시계가 멈춘다)
- **HTTP 경로**: `409` 반환, `confirm=진행` 을 붙여 재요청해야 실행
- 통과해야 비로소 전체 권한으로 재호출한다

대답은 넷으로 갈린다:

| 대답 | 판정 | 동백 반응 |
|---|---|---|
| 진행 / 승인 / 그래 / 오케이 / 좋아 | 승인 | 실행 |
| 아니 / 취소 / 하지마 / 됐어 | 거부 | 즉시 취소 |
| **기다려 / 잠깐만 / 조금만** | **보류** | 대기를 2분으로 늘리고 기다림 |
| 그 외 | 불명 | 오인식 후보 기록 후 한 번 되묻기 |

부정어가 섞이면 무조건 취소다 ("잠깐, 아니 취소" 는 취소).

한빛기획 고유 위험도 게이트에 들어 있다: 광고 집행·예산·입찰 변경(네이버/카카오/
구글/메타), 세금계산서·현금영수증 발행, 홈택스 신고, 고객사 계정 조작, 계약 해지,
인보이스·알림톡·문자 발송. 전부 '대상+행위' 짝이라 **조회는 걸리지 않는다**
("네이버 광고 성과 알려줘" 통과, "네이버 광고 집행해" 게이트).

## 밖에서 부르기 — 텔레그램

집 밖에서 음성으로 동백을 부른다. 음성메시지를 보내면 맥이 받아쓰고, 처리하고,
텍스트와 음성으로 답한다. 포트를 인터넷에 열지 않는다.

```
텔레그램 음성메시지 → whisper 받아쓰기 → 동백 라우터 → 텍스트 + 음성 답장
```

### 비용 — 통로가 아니라 명령 종류가 가른다

**텔레그램이라서 더 드는 토큰은 없다.** 받아쓰기(whisper)와 음성합성(Supertonic)은
마이크로 부르든 텔레그램으로 부르든 맥에서 로컬로 돌아 0원이다.
텔레그램 API 도 무료고 음성 한 건이 8KB 수준이다.

비용을 가르는 건 **동백이 그 명령을 로컬로 처리할 수 있느냐** 하나뿐이다.

| 명령 | 왕복 | Claude 호출 | 비용 |
|---|---|---|---|
| "이번 주 일정 알려줘" | 0.24초 | 0회 | **0원** |
| "안 읽은 메일 몇 통이야" | 0.33초 | 0회 | **0원** |
| "지금 몇 시야" | 즉시 | 0회 | **0원** |
| "광고플랫폼 최근 커밋?" | 27.4초 | 1회 | ~1,018원 |

(위는 실측값. 마지막 항목은 도구를 여러 번 쓰는 명령이라 비싸다)

로컬로 처리되는 명령의 왕복 세부: 받아쓰기 0.47초 + 처리 0.35초 + 음성합성 3.95초.
텍스트를 먼저 보내고 음성은 뒤따라 보내므로 체감은 ~0.8초.

### 설정

**⚠ 반드시 동백 전용 봇을 새로 만들 것.**
 텔레그램 `getUpdates` 는 한 번
읽으면 메시지가 사라져서, 두 프로그램이 서로 메시지를 뺏어간다. 먼저 읽는 쪽이
가져가고 다른 쪽은 영영 못 받는다. 헤르메스 게이트웨이가 죽는다.

1. 텔레그램에서 `@BotFather` 에게 `/newbot` → 이름 정하고 토큰 받기
2. 새 봇에게 아무 메시지나 한 번 보내기 (그래야 봇이 대화를 인식한다)
3. 설정 파일 작성:

```bash
cat > ~/dongbaek/state/telegram.json <<'EOF'
{
  "bot_token": "여기에_BotFather가_준_토큰",
  "allowed_chat_ids": [123456789]
}
EOF
chmod 600 ~/dongbaek/state/telegram.json
```

`allowed_chat_ids` 에 없는 사람이 보내면 **응답조차 하지 않는다.**
비워두면 아무도 허용되지 않는다 (열어두는 것보다 낫다).

4. 실행 — launchd 로 상시 등록돼 있어 재부팅해도 자동으로 뜬다:

```bash
launchctl list | grep dongbaek-telegram     # 상태 확인
launchctl kickstart -k gui/$UID/com.dongbaek.dongbaek-telegram   # 재시작
```

수동으로 띄우려면 (`launchctl unload` 후):

```bash
~/dongbaek/.venv/bin/python ~/dongbaek/telegram_bridge.py
```

### 원격에서도 안전 게이트는 그대로

밖에 있다고 느슨해지지 않는다. 위험 명령을 보내면 되묻는다.

```
나:   🎤 "프로덕션 배포해줘"
동백: ⚠ '배포' 가 포함된 되돌릴 수 없는 작업입니다.
      실행하려면 '진행' 이라고 답장해 주세요. (3분 내)
나:   진행
동백: (실행)
```

`네`, `어`, `응` 으로는 승인되지 않는다. 3분이 지나면 만료된다.

## 로컬 처리 (0 토큰)

아래는 Claude 를 거치지 않고 맥에서 직접 처리한다. 토큰 0, 0.3초 내외.

| 명령 | 구현 | 비고 |
|---|---|---|
| 시간·날짜·타이머·볼륨 | `router.handle_local` | 즉시 |
| **음악** — "아이유 밤편지 틀어줘" | 유튜브 검색 첫 곡을 기본 브라우저로 | "음악 꺼줘" 는 유튜브 탭 닫기 |
| **안 읽은 메일 / 최근 메일** | `mail_local.py` (AppleScript) | 0.4초 |
| **일정 조회** | `calendar_local.py` (EventKit) | 0.3초 |
| **일정 등록·삭제·시간 옮기기** | 동일 + `korean_time.py` | 승인 없이 바로 (2026-08-12 지시) |
| **메일 알림 켜고 끄기** | `mail_alert.py` | "메일 오면 알려줘" |
| **통화 일정 후보 등록** | `call_notes.py` | 여쭙고 "응" 하시면 |

> 📌 일정 쓰기에는 승인 대신 **길이 문턱**이 있다 — 원문 200자, 제목 40자를
> 넘으면 손대지 않는다. 2026-08-14 에 구술하신 미팅 내용(3,499자)이 통째로
> 일정이 되어 아홉 건이 박힌 뒤에 세운 것이다. 지시는 짧고, 긴 말은
> 받아쓰기다.

> 📌 시각·날짜·일정은 **그것만 물었을 때**만 로컬이 답한다.
> "내일 미팅이 2시인데 몇 시에 나가야 해?" 는 추론 질문이라 Claude 로 간다.
> ("몇시" 부분일치로 시계를 읽어주다 엉뚱한 답이 나간 실사례)

> 📌 캘린더는 EventKit 을 쓴다. AppleScript 의 `every event whose ...` 는
> 같은 조회에 **3분이 넘어도 안 끝난다** (이벤트마다 AppleEvent 왕복).
> EventKit 은 DB 에 술어를 넘겨 0.3초에 끝난다.

### 안전 규칙 — 순서가 중요하다

`dongbaek.handle()` 은 **위험 판정을 로컬 처리보다 먼저** 한다.

```
명령 → ① DANGER_PATTERNS 판정 → (걸리면) 음성 승인
     → ② 로컬 처리 (승인됐으면 쓰기도 가능)
     → ③ Claude
```

반대로 두면 일정 등록 같은 되돌릴 수 없는 작업이 **음성 확인을 건너뛴다**.
`test_local.py` 가 이 경로를 회귀 테스트로 고정하고 있다.

### 로컬이 일부러 손대지 않는 경우

확신이 없으면 처리하지 않고 Claude 로 넘긴다. 어설픈 추측보다 낫다.

- 날짜나 시각이 불명확 — "내일 미팅 잡아줘" (시각 없음)
- 삭제 대상이 껍데기 말뿐 — "내일 미팅 취소해줘" → 제목이 `미팅` 으로만 추출됨
- 캘린더 권한 없음 — `calendar_local` 이 `None` 을 돌려주면 자동 폴백

## 토큰 비용

STT·TTS·호출어 판정·로컬 처리는 전부 로컬이라 **0 토큰**. Claude 호출에서만 나간다.

| 명령 유형 | 실효 입력 | 비고 |
|---|---|---|
| 로컬 처리 (시간·타이머·볼륨) | 0 | Claude 안 감 |
| 단순 질문 (세션 재사용) | ~25k 캐시읽기 | 약 19원 |
| 단순 질문 (새 세션) | ~25k 캐시쓰기 | 약 140원 — **7배 비쌈** |
| 도구 2~3회 | ~150k | 약 60원 |

**세션은 모델별로 따로 잡는다.** 소넷과 오퍼스를 한 세션에서 번갈아 쓰면
모델이 바뀔 때마다 프롬프트 캐시가 무효화돼 아래 7배 차이가 매번 되살아난다.
`state/session.json` 이 `{모델: {session_id, updated_at}}` 형태인 이유다.

**세션 재사용이 최대 절약 레버다.** `bridge.py` 가 `state/session.json` 에
세션 ID를 보관하고 `--resume` 으로 붙는다 (24시간 지나면 자동 폐기).

그다음 레버는 **MCP 다이어트**다. `.mcp.json` 을 비워둔 이유가 이것 —
서버를 붙일수록 명령 한 번의 고정 비용이 커진다. 음성으로 실제 쓰는 것만 추가할 것.

사용량 확인: `state/tokens.jsonl`, 또는 음성으로 "동백, 토큰 얼마나 썼어".

## 메일 정리 — 매일 오전 11시

받은 메일을 읽고 업무 일정을 찾아낸다. 미팅이면 `[미팅]`, 그 외 업무 일이면
`[업무]` 를 붙인다. 끝나면 동백이 결과를 말해준다.

> ⚠ **캘린더 자동 등록은 꺼져 있다** (`mail_digest.CALENDAR_ENABLED = False`,
> 2026-08-14 지시). "메일만 보고 뽑은 일정은 정확하지 않다" — 정크 정리와
> 보고는 계속하되 등록은 하지 않는다. 켜려면 그 값을 True 로 바꾼다.

```bash
launchctl kickstart -k gui/$UID/com.dongbaek.dongbaek-mail   # 지금 한 번
~/dongbaek/.venv/bin/python ~/dongbaek/dongbaek.py --mail-digest-dry  # 등록 없이 확인만
```

**비용 구조가 설계 전부다.** 할 수 있는 건 전부 로컬에서 한다.

| 단계 | 방법 | 비용 |
|---|---|---|
| 메일 읽기 | AppleScript (`mail_local`) | 0 |
| 후보 고르기 | 정규식 | 0 |
| **일정 뽑기** | **Claude 소넷 1회** | **≈$0.08** |
| 캘린더 등록 | EventKit (`calendar_local`) | 0 |

거르는 기준은 **날짜·시각이 적혀 있는가** 하나다. 처음엔 일정 낱말
(미팅·회의·세미나…)도 함께 요구했는데 실측에서 '스마트축산 경진대회 3차콜',
'농업박람회 부스 시공' 같은 진짜 업무 메일이 낱말 목록에 없다고 빠졌다.
업무 어휘는 무한해서 목록으로 못 따라잡는다 — 위험 표현을 쫓다 실패했던 것과
같은 함정이다. 반대로 날짜가 없으면 애초에 일정을 만들 수 없다.
넓게 통과시키고 판단은 소넷이 한다. 실측 28통 중 7통 통과.

> 📌 **한 번짜리 호출은 도구·MCP·기본 시스템 프롬프트를 전부 뺀다**
> (`bridge.ask_once`). 텍스트를 JSON 으로 바꾸는 데 도구가 필요 없는데
> 그냥 두면 도구 설명과 MCP 목록이 매번 입력으로 실려 간다.
> 실측 실효입력 56,948 → 7,257 (87% 감소), $0.269 → $0.035.

일정 자동 등록은 기본이 꺼져 있다(`mail_digest.CALENDAR_ENABLED = False`,
2026-08-14 사장님 지시 — 메일만 보고 뽑은 일정은 부정확하다). 정크 메일
정리는 그대로 돈다. 등록 로직 자체는 다음 원칙으로 좁게 잡혀 있다:

- 날짜와 시각이 **메일에 명시된** 것만. 추측하면 버린다.
- 지난 일정은 넣지 않는다.
- 한 번에 8건까지.
- 같은 메일도, 같은 일정도 두 번 넣지 않는다 (`state/mail_digest.json`).
- `--mail-digest-dry` 는 기록을 남기지 않는다 — 남기면 '본 메일' 로 찍혀
  정작 진짜 실행이 그 메일을 건너뛴다.

## 자기 코드를 고치면 스스로 재시작한다

동백은 자기 코드를 고칠 수 있는데, 고쳐도 **돌고 있는 프로세스는 옛 코드**다.
그대로 두면 "고쳤습니다" 라는 답만 듣고 동작은 그대로인 상태가 반복된다.

그래서 자기 저장소(`~/dongbaek`)를 고쳤을 때는 답변을 전한 **뒤에**
데몬과 텔레그램 브릿지를 **함께** 갈아끼운다.

> ⚠️ **둘을 같이 재시작해야 한다.** `config` 는 기동할 때 메모리에 올라가는데
> `dongbaek` 은 명령이 올 때 디스크에서 새로 읽힌다. 한쪽만 재시작하면
> 새 코드가 옛 `config` 를 참조해 `AttributeError` 로 죽는다.
> 실제로 텔레그램에서 그렇게 터졌다 (데몬만 재시작한 탓).

재시작 전에 `~/dongbaek/*.py` 가 전부 파싱되는지 확인한다. 하나라도 깨져 있으면
재시작하지 않고 "문법 오류가 있어 새 코드로 바꾸지 않았습니다" 라고 알린다.
깨진 코드로 재시작하면 크래시 루프에 빠지고, 그러면 **"되돌려" 라고 말할 상대조차
없어진다.** 끄려면 `config.SELF_RESTART_ENABLED = False`.

> 📌 이 문법 게이트는 한 번 조용히 무력화된 적이 있다. `py_compile` 에
> `cfile=os.devnull` 을 주면 "정규 파일이 아니다" 며 **컴파일하기도 전에**
> `OSError` 를 던지는데, '읽을 수 없는 파일은 넘어가자' 는 `except` 가 그걸
> 삼켜서 모든 파일이 통과됐다. 지금은 파일을 만들지 않는 내장 `compile()` 을 쓴다.

## 동백이 한 일 들여다보기

동백은 별도 프로그램이지만 **속은 그냥 Claude Code 다** (`claude --print` 를 실행한다).
그래서 대화가 진짜 Claude Code 세션으로 남고, 터미널에서 이어받을 수 있다.

**① 활동 로그** — 들은 말·명령·답변·비용·차단 이력

```bash
~/dongbaek/.venv/bin/python ~/dongbaek/dongbaek.py --log
```

**② 세션 이어받기** — 음성으로 시키던 걸 키보드로 계속

```bash
claude --resume $(~/dongbaek/.venv/bin/python -c "import sys;sys.path.insert(0,'$HOME/dongbaek');import bridge;print(bridge.latest_session())")
```

**③ 원본 기록**

기록의 정본은 `state/dongbaek.db` 다 (2026-08-16 지시). 예전엔 jsonl 과
나란히 쌓았는데, 같은 것이 두 곳에 있으면 갈라지는 날 어느 쪽이 사실인지
가릴 근거가 없다. 읽는 쪽 여덟 곳을 전부 `dbstore` 로 옮겼다.

```bash
sqlite3 ~/dongbaek/state/dongbaek.db \
  "select ts, route, command, reply from transcript order by id desc limit 5"
```

| 파일 | 내용 |
|---|---|
| `state/dongbaek.db` | **정본.** 무엇을 듣고 무엇을 했나 (SQLite `transcript` 표) |
| `state/memory.db` | 장기 기억 (행마다 임베딩) |
| `state/transcript.jsonl` | 구명정. DB 쓰기가 실패한 건만 여기 적힌다 |
| `state/tokens.jsonl` | 호출별 토큰·비용 |
| `state/daemon.log` | launchd 실행 시 콘솔 출력 |
| `~/.claude/projects/-Users-me-dongbaek/` | Claude 세션 원본 |

## 접근 범위

`config.py` 의 `CLAUDE_EXTRA_DIRS` 가 동백이 볼 수 있는 폴더다.

| 경로 | 쓰임 |
|---|---|
| `~/projects` | 코드·git — "개발 어디까지 됐어?" |
| `~/.claude/projects` | 과거 대화 — "어제 그 세션에서 뭐라고 했지?" |

> ⚠️ **`--allowed-tools` 는 화이트리스트가 아니다.** 사전승인 목록일 뿐이라,
> 목록에 없는 명령도 그대로 실행된다 (`echo` 로 실측 확인).
> 따라서 `Bash` 를 `NORMAL_DISALLOWED` 에서 빼면 평상시에도 전권 셸이 열린다.
> 과거 대화 검색은 Bash 없이 **Glob·Grep 도구만으로** 되는 것을 확인했으니,
> `Bash` 는 계속 차단해 둘 것.

범위를 넓혀도 **기본은 읽기 전용**이다 — 평상시 `Bash`·`Write`·`Edit` 가 차단되고,
되돌릴 수 없는 작업은 `DANGER_PATTERNS` 게이트를 통과해야만 실행된다.
그래서 범위를 넓힐수록 그 목록이 더 중요해진다.

## 음성 엔진

`config.py` 의 `TTS_ENGINE` 으로 고른다. 기본은 `supertonic`.

| | macOS `say` | Supertonic |
|---|---|---|
| 음질 | 기계음 (compact Yuna) | 신경망 합성 |
| 첫 소리까지 | ~0.1초 | ~0.5초 (문장 파이프라이닝) |
| 생성 속도 | — | 실시간의 5~7배 |
| 모델 로딩 | — | 0.3초 (캐시됨) |

Supertonic 은 wav 를 다 만들어야 재생되므로 긴 답변일수록 앞에서 기다린다.
그래서 `tts.py` 가 **문장 단위로 쪼개** 첫 문장만 만들어 재생을 시작하고
나머지는 재생 중에 만든다. 생성이 재생보다 6~7배 빠르므로 뒤가 밀리지 않고,
첫 소리까지의 시간이 답변 길이와 무관하게 ~0.5초로 고정된다.

합성이 실패하면 자동으로 `say` 로 내려간다 (목소리가 아예 없는 것보다 낫다).

목소리 바꾸기: `TTS_SUPERTONIC_VOICE` 를 `M1`(남) / `F1`(여) 로.

### 숫자·시각은 한글로 확정해서 보낸다

숫자를 아라비아로 두면 그 다음은 TTS 손이다. 실제로 이렇게 나갔다 —
`08:34` → "공팔 삼사", `12:58` → "십이시 오십팔분", `3.5시간` → "삼점오",
`32GB를` → "삼십이지비를". 그래서 `speak.clean()` 이 **소리로 나가기 전에**
한글로 바꾼다.

| 원문 | 나가는 소리 |
|---|---|
| 3.5시간 | 삼쩜오시간 (정수부는 자릿수, 소수부는 한 자씩) |
| 12:58 | 열두시 오십팔분 (1~12시는 고유어) |
| 14:00부터 | 십사시부터 |
| 오늘 일정 14:00 (브리핑) | **오후 두시** (`speak.clock_ampm`) |
| 3:1 | 3대 1 (시각이 아닌 콜론은 비율) |
| 32GB를 | 32기가바이트를 |

⚠ 두 가지가 되풀이해서 발목을 잡았다.

1. **경계를 `\b` 로 잡으면 한국어에서 안 선다.** 조사가 숫자에 딱 붙어
   오기 때문이다("14:00부터", "32GB를"). 한글도 낱말 문자라 경계가 없어
   규칙을 통째로 건너뛴다. 숫자만 배제하는 전후탐색으로 잡는다.
2. **시각을 만드는 자리가 여럿이면 한쪽만 고쳤을 때 또 어긋난다.**
   지금은 여섯 곳이 전부 `speak.clock_words()` / `clock_ampm()` 을 본다.

> 📌 **macOS 기본 음성도 무료로 개선된다.**
> 시스템 설정 → 손쉬운 사용 → 음성 콘텐츠 → 시스템 음성 → 음성 관리 에서
> 한국어 **고품질/프리미엄** 을 받으면 폴백 음질이 올라간다. 지금은 compact 만 깔려 있다.
